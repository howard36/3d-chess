# Verification: foundations

How to run this file: bring up the local server and client as in [the protocol](README.md#how-to-run-a-pass). Unless a row says otherwise, the setup is a **new game with both seats taken**: create a game in one browser context, join it from a second, and note which page is White (the seat label says "You are playing as white."). Leave the view at the default (reload to reset it). Device values: `mouse`, `keyboard`, `touch`, `second player` (the other context), `second tab` (same context as the player), `drop` (see [devices and conditions](README.md#devices-and-conditions)), `narrow`. Several expected results are read back from the console handle described in [the protocol](README.md#driving-the-product-from-a-console-or-script); those rows say so.
