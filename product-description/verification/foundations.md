# Verification: foundations

How to run this file: bring up the local server and client as in [the protocol](README.md#how-to-run-a-pass). Unless a row says otherwise, the setup is a **new game against a friend with both seats taken**: pick a side on `/new` in one browser context, join from a second, wait for both entrances to end, and note which page is White (its turn pill shows the porcelain stone at the left). Leave the view at the default (reload to reset it) in a 1280 × 720 window. "Press" means a left click (or a tap) on the board, released where it went down. "Play `X-Y`" means the side to move presses `X`, then `Y`. Device values are defined in [devices and conditions](README.md#devices-and-conditions). Several expected results are read back from the page as described in [the protocol](README.md#driving-the-product-from-a-console-or-script); those rows say so.

Rows whose behavior no longer exists are kept, retired, so their IDs are not reused.
