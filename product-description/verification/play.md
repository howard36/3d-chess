# Verification: play

How to run this file: bring up the local server and client as in [the protocol](README.md#how-to-run-a-pass). Unless a row says otherwise, the setup is a **new game against a friend with both seats taken** in two browser contexts, both entrances over, with the view at the default. "Play `X-Y`" means the side to move presses `X` and then `Y`; lines alternate White, Black, White. The **promotion line** is `Be2-Ce2`, `Eb5-Ca5`, `Ce2-Ce3`, `Ca5-Ab5`, `Ce3-De4`, `Ab5-Ca5`, after which White's pawn on `De4` can capture onto White's promotion square `Ee5` (or onto `Dd5` and `Ed4`, which do not promote). The **mate line** is `Ad1-Ac3`, `Ec4-Cc2`, `Ac2-Ad1`, `Cc2-Bb1` (Black mates). The **repetition line** is `Ab1-Aa3`, `Eb5-Ea3`, `Aa3-Ab1`, `Ea3-Eb5`, played twice (a draw on the eighth move). Device values are defined in [devices and conditions](README.md#devices-and-conditions). **Reduced motion** means the browser emulating `prefers-reduced-motion: reduce` before the board screen appears.

> **Status at `24c650c`.** This file was rewritten for `24c650c` (the new starting position, so new lines; the turn pill and the hidden move card; the glass tower's marks and motion; the draws; the result card that can be closed). Every row's Result is `unverified` unless it names a later pass; the Results of the scripted pass at `c571311` are in this file's history. Retired rows keep their IDs.
