# Verification: start

How to run this file: bring up the local server and client as in [the protocol](README.md#how-to-run-a-pass). Each section starts from fresh browser contexts (no stored seats) unless it says otherwise. Device values are defined in [devices and conditions](README.md#devices-and-conditions); `server stopped` means the local server process is not running (stop it with Ctrl+C and start it again when the step says so), and `storage off` means the browser refuses to store site data for `localhost`.


> **The HUD changed at `f7bff4d`.** The seat label ("You are playing as white."), the presence line ("Opponent: online/offline"), the turn indicator's words ("White to move — in check"), and the always-visible move box and move list are gone: the [turn pill](../game-page/turn-indicator.md) shows the turn, the seat, check, and an offline opponent; the move box and list live in the [move card](../game-page/move-list.md), never shown as a panel: its list is in the page for screen readers only, and its move box appears alone while it has keyboard focus (Tab). Read "the move list shows X" as the hidden "Move history" list in the accessibility tree, or the announcer's `data-last-move` and `data-move-count`. Rows in this file that quote the old words or press the old panels test the same behavior through the new HUD (read "White to move" as White's half of the pill lit, the seat label as the player's stone, "Opponent: offline" as the outlined stone and "Offline", "type in the move box" as Tab, then type), and their results were recorded against the old HUD: re-run them. [game-page.md](game-page.md) has been rewritten for it.

> **The start screen became a landing page after `4e18386`.** A live 3D preview of the tower (a sample game playing itself while the camera circles it) fills the window, with a "Pause preview" button at the top right. The button reads "Start a game" (was "Start New Game"), and "Creating game…" while in flight (was "Creating Game..."). Nothing is written under the button (a later change removed the line there, with the preview's "Checkmate · White wins"): a click that has to wait for the connection makes the button read "Connecting…" or "Reconnecting…" (the connection's state used to show whenever the connection was not open), with a visually hidden status saying "Connecting to server…" or "Reconnecting to server…"; and an error turns the button to "Try again", the message, "Couldn't start a game: …" (was "Error: …"), only in a visually hidden alert and the button's tooltip. The title and the button stand centered in bands of one height above and below the tower. While in flight the button is no longer disabled in the HTML sense: it is marked unavailable (`aria-disabled`), ignores presses, and keeps focus. Read "disabled" in the rows below that way. The rows below use the new labels, but their results were recorded against the old start screen and quote its words: re-run them. CREATE-09 to CREATE-15 are new and have not been run.
