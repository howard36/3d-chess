# Verification: start

How to run this file: bring up the local server and client as in [the protocol](README.md#how-to-run-a-pass). Each section starts from fresh browser contexts (no stored seats) unless it says otherwise. Device values are defined in [devices and conditions](README.md#devices-and-conditions); `server stopped` means the local server process is not running (stop it with Ctrl+C and start it again when the step says so), and `storage off` means the browser refuses to store site data for `localhost`.

> **The pre-game flow was rebuilt at `1928567`** (and its wording and handover revised at `f38fcdb`, which the items below follow). "Start a game" no longer creates a game: it opens the side choice at `/new`, where the player picks White, Random, or Black among three kings on a sheet of glass, and the pick creates the game. The share-link, join, and joined screens are gone: the host sees an invitation to send ("Invite a friend") and the guest an invitation to the free seat ("You're invited to play …", "Take your seat"), both over the lobby's scene, and the game starts with an arrival and a handover to the board's entrance. The documents were rewritten from the code and not checked in the running app. The old items (CREATE-01 to CREATE-14, WAIT-01 to WAIT-12, JOIN-01 to JOIN-10) tested the old screens and are retired; their results are in this file's history before the rewrite. The items below are new, and none has been run: every Result reads `unverified`.
