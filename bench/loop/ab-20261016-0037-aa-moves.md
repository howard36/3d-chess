# A/B benchmark comparison

Base `e02a235` (`e02a235`) against this checkout (`e02a235` with uncommitted changes), 6 interleaved pairs (base then head, then head then base, ...) of browser (--only); both sides run this checkout’s benchmark code. 9 min. Generated by `node bench/run.mjs --primary --only browser --browser-sections move-latency --base e02a235 --pairs 6 --out bench/out/ab-aa-moves.md`.

A *pair* is one run of the base and one of the head, made back to back, so if the machine speeds up or slows down during the comparison, both sides feel it. Each pair gives a ratio, head divided by base. A change is called **better** or **worse** only when every pair moves the same way, by more than 5% and by more than the pairs disagree with each other (the range of their ratios). Otherwise the change is shown but not called. A value of 0 on one side has no ratio: that row is judged by the pairs’ differences instead, and called when every pair moves the same way.
